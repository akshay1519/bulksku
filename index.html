Wholesale ordering on WooCommerce is broken

If your buyers place large orders, the default WooCommerce experience creates unnecessary friction.

😤

Click. Click. Click.

Wholesale buyers search for each SKU individually, add to cart, repeat — 50 times per order. It takes forever.

❌

No stock visibility upfront

Buyers find out at checkout that half their items are out of stock. Orders get cancelled or re-placed.

📋

Buyers already have SKU lists

Your B2B customers work from spreadsheets, order forms, or distributor price lists. They just want to paste and go.

How BulkSKU fixes it

A focused plugin that solves exactly one problem: getting large SKU lists into a WooCommerce cart fast.

✓

Paste-and-validate input

Buyers paste their SKU + quantity list from any source — spreadsheet, email, order form.

✓

Instant stock feedback

Each SKU is validated against WooCommerce stock before the cart is touched. Invalid SKUs are flagged clearly.

✓

CSV upload support

For larger orders, buyers can upload a CSV file instead of pasting. Same validation, same outcome.

✓

One-click bulk add

Valid items are added to the WooCommerce cart in a single action. No repeated form submissions.

✓

Works with your existing store

Built on WooCommerce APIs. No external service, no subscription, no data sent anywhere.

✓

Self-hosted & private

All processing happens on your own WordPress server. Customer order data never leaves your site.

Frequently asked questions

Is the plugin available right now?
No — not yet. This page validates demand before I build it. I'd rather be honest about this than pretend the plugin already exists. To be notified when it ships: star or watch this repo on GitHub, or open an issue to express interest.
What WooCommerce version does this require?
The planned MVP targets WooCommerce 7.0+ and WordPress 6.0+. Support for older versions is not planned for v1.0, but may be added based on feedback.
Why $39 one-time instead of a subscription?
Wholesale store plugins are infrastructure, not SaaS. A one-time purchase is fair for something that installs on your server and doesn't phone home. I don't want your money every month for code you already own.
Does BulkSKU send any data to external servers?
No. The plugin runs entirely within your WordPress/WooCommerce installation. All SKU validation happens against your own WooCommerce database. No data is sent to my servers or any third party.
Does it work with product variations (size, color, etc.)?
Yes — variation support is planned for v1.0. Buyers can specify a variation SKU (WooCommerce assigns unique SKUs to each variation) and the plugin will validate the correct stock level.
What if I need a feature that's not in the v1.0 scope?
Email me or open a GitHub issue. I'm building v1.0 based on the most common wholesale ordering pain points. If your use case is common, it'll influence the roadmap. If it's niche, I'll be honest that it might not make v1.0.
What's your refund policy?
A fair refund policy will be confirmed and published here before any checkout goes live. No payment is currently possible from this page — a refund policy only becomes relevant once a verified checkout URL is configured and the plugin is deliverable.
